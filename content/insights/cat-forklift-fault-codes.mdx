Cat internal-combustion forklifts built by Mitsubishi Caterpillar Forklift America (the GP15N–GP35N and GC15N–GC35N series, roughly 2005 onward) use the Nissan K21 or K25 engine and show engine faults on the meter panel as an **E-code**: E-21, E-32, E-43 and so on. The same engine and control module appear in Mitsubishi FG/FGC-N trucks and Nissan/UniCarriers Platinum-series trucks, so the table below applies to all three badges.

If your truck is an electric Cat (EP or ET series, or the older 2EC/2EP), it uses a different controller and numeric code set. That family is not covered here; the codes below will not match.

## How the codes show up

A current fault shows on the LCD meter panel as "E" and a two-digit number while the key is on. Most codes also switch on the engine warning lamp. Some faults put the truck in a reduced-power mode; a few (E-27, E-28, E-30) usually stop it.

The code clears itself once the underlying condition is gone and the key is cycled. A stored history stays in the ECM and is read with the dealer diagnostic tool or the panel's diagnostic mode. If a code returns immediately after the key cycle, the fault is still present; if it returns days later, it is intermittent and usually a connector or harness problem.

## The three codes people search for most

**E-43 (LPG air/fuel ratio)** is the most common code on these trucks because it is downstream of several cheap parts. Work in this order: air filter (a dirty flame-retardant element on a Cat lifts the mixture rich), LPG tank valve and hose for a restriction, vaporizer outlet pressure, then the main injector. A long crank before the code appears points toward fuel pressure rather than the mixture sensors. See the [E43 diagnostic walkthrough](/insights/e43-code-nissan-forklift) for the step-by-step.

**E-32 (coolant overheat, stage 1)** is a real temperature event, not a sensor code. Check the radiator fins first; on a Cat in a lumber yard or recycling facility the core is usually packed. Then coolant level, fan belt, fan clutch, and the thermostat. If the operator rides the inching pedal, the torque converter heats the transmission oil, which shares the cooler.

**E-27 (crankshaft position sensor)** shows as an extended crank or no-start. Verify fuel pressure before condemning the sensor, because a starving engine that eventually catches produces the same symptom. If fuel is right, measure the sensor and check its wiring for chafing where the harness passes the block.

## Clearing a code

Fix the cause, cycle the key, and confirm the display is clear. Codes E-24 and E-41 have their own quirks: E-24 needs the accelerator "key learn" procedures after any pedal or sensor work, and E-41 needs the brake pedal held while the code is cleared. If the same code returns with nothing else changed, the fault is still present, not a stale memory.

## Frequently asked questions

**Are Cat and Mitsubishi forklift codes the same?**
For IC trucks with the K21/K25 engine, yes. Both are built by Mitsubishi Caterpillar Forklift America on the same platform, and the ECM code set is identical. UniCarriers/Nissan Platinum-series trucks with the same engine share it as well.

**Why does my code go away and come back?**
An intermittent code is almost always a connector or harness issue: corrosion in a relay box, a chafed wire, or a loose pin. Wiggle-test the harness with the key on and watch for the code to set.

**Does E-43 mean the truck is unsafe to run?**
It means the mixture is out of range. The truck will usually run, but rich operation fouls the plugs and O2 sensor and raises CO in an enclosed building. Address it promptly.

**What does the truck do on E-32?**
Stage-1 overheat typically derates the engine. Stage 2 (E-33) is a shut-down condition. Do not keep operating through either.

**Can I read stored codes without the dealer tool?**
Current codes display on the meter panel with the key on. Stored history requires the dealer diagnostic software or the panel's service mode, which is described in the truck's service manual for your model.
